RUN IT ON YOUR OWN COMPUTER

One command. Your existing GitHub access.

Install Node 22+ and sign in with GitHub CLI. Replace OWNER/REPO and NUMBER below.

npm exec --yes \
  --package=https://github.com/builtbysharath/gh-pr-check-explainer/releases/download/v0.1.0/gh-pr-check-explainer-0.1.0.tgz \
  -- gh-pr-check-explainer --repo OWNER/REPO --pr NUMBER

You can also select the command and copy it manually.

npm downloads the pinned GitHub release and its dependencies. The CLI reads GitHub using your existing gh access. It never posts comments, reruns workflows or changes policy.

BEFORE YOU RELY ON A RESULT

What does the verdict cover?

Does it explain every reason a PR cannot merge?

It covers required status checks and observed strict branch freshness. Reviews, conflicts, deployments and merge-queue readiness are outside the verdict. Matrix and reusable-workflow expansion are not supported.

What if the evidence is incomplete?

Unavailable permissions, ambiguous check names and unsupported workflow patterns stay explicitly uncertain. A missing result is not proof of a broken workflow. Read the report's coverage notes.

Can I upload a private snapshot here?

This website has no upload or login form. Run the CLI locally. Saved reports and snapshots can contain private workflow contents; sanitize them before sharing.
