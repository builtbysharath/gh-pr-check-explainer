# Security and data handling

This experimental tool has not received a formal security audit. Inspect only files or repositories you are authorized to read. Reports can contain private data and must be reviewed before sharing.

Report a security defect through [GitHub private vulnerability reporting](https://github.com/builtbysharath/gh-pr-check-explainer/security/advisories/new). Do not put exploit details or private data in a public issue. Supported fixes currently target the latest 0.1.x release.

The tool provides evidence and review guidance; it does not certify merge readiness, document privacy or malware safety. See README coverage and limits.
